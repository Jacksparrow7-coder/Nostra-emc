# 🛍️ Nostra – E-commerce Website

A fully responsive **E-commerce website** built using **HTML, CSS, and JavaScript** as part of my 5-week front-end development project.

---

## 🚀 Project Overview

**Nostra** is a modern online shopping website featuring product collections, filters, and a search bar.  
It’s designed to deliver a smooth user experience across all devices.

---

## 🧩 Pages Included

- 🏠 **Home Page (index.html)** – Hero section, brand showcase, and new arrivals  
- 🛒 **Collections Page (collections.html)** – Product listings with **search** and **filter** functionality  
- ✉️ **Contact Us Page (contact.html)** – Simple contact form for user queries  

---

## ⚙️ Functionality

- 🔍 **Search Feature:** Quickly find products by name  
- 🧭 **Filter System:** Filter products by category using JavaScript  
- 📱 **Responsive Design:** Optimized for desktop, tablet, and mobile devices  

---

## 🧠 Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling and responsiveness  
- **JavaScript (ES6)** – Dynamic features (search + filter)

---

## 📅 Project Duration

**5 Weeks** – Planned, designed, and coded end-to-end.
